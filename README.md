# 🏥 Healthcare Data Analytics Dashboard

## 📌 Project Overview

This project is an interactive Healthcare Data Analytics Dashboard built using Power BI. It analyzes patient records, billing information, medical conditions, gender distribution, and monthly trends to help healthcare organizations make data-driven decisions.

The dashboard includes KPIs, charts, drill-through pages, tooltips, slicers, bookmarks, and DAX measures for better business insights.

---

## 🚀 Features

- Total Patients KPI
- Male & Female Patient Analysis
- Total Billing Amount
- High Billing Patient Analysis
- Average Billing by Gender
- Monthly Patient Trend
- Medical Condition Analysis
- Billing Category Analysis
- Interactive Filters (Gender & Medical Condition)
- Drill Through Page
- Custom Tooltip Page
- Navigation Button
- Bookmarks
